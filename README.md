# 3D-модель филиала «Интергаз Центральная Азия» — УМГ «Уральск»

Интерактивная real-time 3D-модель здания и территории УМГ «Уральск» на Three.js (AgX tone mapping, PMREM IBL, мягкие тени, 60 FPS, без внешних CDN-зависимостей).

## Живая версия
- **GitHub Pages:** https://tagiriskaliev18-hash.github.io/icamodel/

## Режимы
- **Дрон:** свободный 6-DOF полёт (`WASD`, `Q/E`, `Shift`, мышь/колесо) + кинематографический авто-облёт и 5 ракурсов (`Фасад`, `Сверху`, `Ротонда`, `Вход`, `Холл`).
- **Человек:** прогулка от первого лица с коллизиями стен/пола/лестниц (можно зайти в холл и подняться по винтовой лестнице); при взгляде вниз видны тело и ноги персонажа в смокинге.
- **Свет и мобильные:** пресеты `День / Закат / Ночь`, уровни качества `HD / STD / ECO`, адаптивный интерфейс `390×844` с виртуальным джойстиком.

## Локальный запуск
```bash
cd site
npx serve .
```
Откройте в браузере указанный локальный адрес.
